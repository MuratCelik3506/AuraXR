# AuraXR Technical Report

## Goal

AuraXR reconstructs plausible VR hand pose when only wrist/controller state and
object information are available. The deployed path uses an SDF-conditioned LSTM
so the hand pose depends on both recent motion and object geometry.

## Model

`SDFLSTMModel` receives a 29-dim frame feature:

- 25 core features: wrist-to-object direction, distance, approach speed, object
  velocity, wrist rotation, grip category, and object bounding box.
- 4 local SDF features: signed distance and SDF gradient at the wrist query
  point.
- 32-dim object embedding: precomputed from object SDF grids and supplied as a
  separate input.

The model projects frame features to 64 dims, injects the object embedding, runs
a 2-layer LSTM with hidden size 256, and predicts MANO PCA pose, wrist rotation,
and contact probability.

## Training Data

The expected processed dataset is:

```text
data/processed/<source>_mano/<hand>/dataset_mano.h5
```

Supported sources:

- `hot3d_mano`: temporal approach sequences, required.
- `arctic_mano`: optional contact-pose augmentation.
- `dexycb_mano`: optional contact-pose augmentation.

SDF assets live under `data/models/sdf_grids/`:

- `sdf_embed_matrix.npy`
- `sdf_bop_ids.npy`
- Unity export JSONs or grids generated by the SDF utilities.

## Evaluation

Primary metrics:

- `mpjpe_mm`: mean per-joint position error after MANO FK.
- `pa_mpjpe_mm`: Procrustes-aligned MPJPE.
- `mae_deg`: mean absolute pose-angle error.
- `pck_auc_50`: PCK area under thresholds 0-50 mm.
- `approach_mpjpe_mm`: MPJPE on frames where wrist-object distance is below 20 cm.
- `contact_accuracy`: contact-labelled frames with MPJPE below 5 mm.
- `smoothness_accel_mean`: mean absolute second-order pose difference.

Current validation results:

| Hand | MPJPE | PA-MPJPE | MAE | PCK-AUC@50 | Contact@5mm |
|---|---:|---:|---:|---:|---:|
| Left | 6.87 mm | 6.43 mm | 21.28 deg | 0.8625 | 27.36% |
| Right | 7.66 mm | 7.06 mm | 22.56 deg | 0.8469 | 32.44% |

## Runtime

Unity runs the ONNX model one frame at a time:

```text
inputs:
  frame_feat  (1, 29)
  obj_embed   (1, 32)
  h_0         (2, 1, 256)
  c_0         (2, 1, 256)

outputs:
  pose_pca     (1, 15)
  wrist_rot    (1, 6)
  contact_prob (1, 1)
  h_n          (2, 1, 256)
  c_n          (2, 1, 256)
```

Reset `(h, c)` when the hand enters or exits the approach state.
